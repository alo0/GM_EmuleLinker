Many links test page for EmuleLinker

Summary

This page generates valid ed2k links, to check that the popup displays them all, whatever their number. Add ?n=5000 to the address to change the number. The automated test suite checks the same on Chrome (see SPECIFICATIONS.md, § 8): this page is for the other browsers, Firefox in particular.

What to check

  1. Normal mode: the popup lists every link. Scroll it down to the last one, many-links-test-file-number-.mp3.
  2. Edit mode (Ctrl+Alt+M): the edit box holds every link, one per line, without any alert. Scroll it down to the last link, then type a character at the end: it must appear.

Do not send these links to eMule: the files do not exist. If you do, cancel them in eMule afterwards.
